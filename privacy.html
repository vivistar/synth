1. Overview and Scope

This Privacy Policy describes how PRIME ISO Services, LLC ("PRIME ISO," "we," "us," or "our") approaches privacy in connection with the SaaS Synthetic Users Readiness Check application ("Service"). Because the Service is a fully client-side, static web application — meaning all processing occurs within your browser with no PRIME ISO backend server involved — our data practices are fundamentally different from conventional web services.

This Policy applies to all users of the Service, regardless of how they access it (direct file, hosted URL, or embedded deployment).

2. Information We Do Not Collect

Due to the client-side architecture of the Service, PRIME ISO does not collect, receive, store, or process the following categories of information:

  • Text you enter into any form field, textarea, or chat input;
  • API keys you optionally provide;
  • AI-generated outputs, persona prompts, or chat transcripts;
  • Assessment answers or wizard step selections;
  • IP addresses, device identifiers, or browser fingerprints;
  • Usage patterns, click events, or session recordings;
  • Names, email addresses, or any other personally identifiable information.

3. Client-Side Data Processing

All data you enter into the Service is processed exclusively within your browser's JavaScript environment. This includes:

  • Form inputs and configuration fields — retained in browser memory (JavaScript variables) only for the duration of your active session and discarded immediately when the tab is closed or refreshed.
  • API key fields — stored in a password-type DOM input element; never written to localStorage, sessionStorage, cookies, or IndexedDB.
  • Chat transcripts and AI outputs — maintained in a session-scoped JavaScript array (chatLogs) and erased on page reload. The "Export Chat" and "Download Report" features write files directly to your device without transmitting them to any server.
  • Wizard answers and governance scores — computed and rendered in-browser; no data leaves your device.

4. Third-Party AI Services (Google Gemini)

The Service makes API calls to Google Gemini (generativelanguage.googleapis.com) to generate AI-powered analyses and simulated personas. When these calls occur:

  • The text prompts you generate — including scenario descriptions, persona configurations, and chat messages — are transmitted directly from your browser to Google's API endpoint over HTTPS.
  • Google processes these prompts in accordance with its own Privacy Policy and Terms of Service. PRIME ISO does not control, intercept, or receive copies of this data.
  • If you use a Custom API Key, all charges and data handling obligations associated with that key are governed by your agreement with Google.
  • If you use the default session-scoped credential, the session is anonymous and not linked to any PRIME ISO or personal account.

We strongly recommend reviewing Google's Privacy Policy and Gemini API Terms before submitting sensitive business data as prompt content.

5. Cookies and Tracking Technologies

The Service does not set first-party cookies, and PRIME ISO does not deploy any analytics, advertising, or behavioral tracking scripts. The application loads the following third-party CDN resources for functionality and visual rendering only:

  • Tailwind CSS via cdn.tailwindcss.com — for styling;
  • Lucide Icons via unpkg.com — for iconography;
  • Google Fonts (Inter) via fonts.googleapis.com — for typography;
  • Perplexity logo (Lifecycle Rationale view) — rendered from a static CDN URL.

These CDN providers may log standard HTTP request metadata (IP address, user agent, referrer) in accordance with their own policies. PRIME ISO does not receive or have access to these logs.

6. Children's Privacy

The Service is not directed at individuals under the age of 18. We do not knowingly collect any information from children. If you believe a child has used the Service in a way that raises privacy concerns, please contact us.

7. Data Security

Because PRIME ISO does not receive or store user data, our security obligations are centered on the integrity of the application code itself. We commit to:

  • Maintaining the Service as a static HTML file with no hidden data exfiltration pathways;
  • Using HTTPS for all outbound API calls;
  • Not embedding third-party scripts beyond the CDN resources listed in Section 5;
  • Conducting periodic reviews of the application's network activity for unintended data transmission.

8. Your Rights

Because we do not collect or store personal data, most traditional data subject rights (access, deletion, portability) are satisfied by default — there is simply no data held about you to act upon. If you have concerns about data processed by Google Gemini on your behalf, please refer to Google's privacy controls and data deletion tools.

Users in the European Economic Area (EEA), United Kingdom, or California may have additional rights under GDPR, UK GDPR, or CCPA respectively. Given that PRIME ISO collects no personal data, these regulations impose minimal obligations, but we remain committed to full compliance and welcome any inquiry.

9. Changes to This Policy

We may update this Privacy Policy from time to time. The "Last Updated" date at the top of this page reflects the most recent revision. Material changes will be noted prominently. Continued use of the Service after a revision constitutes acceptance of the updated Policy.
