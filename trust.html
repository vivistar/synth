Our Trust Pillars

Architecture & Data Isolation

The Service is a single, self-contained HTML file. There is no application server, no database, no authentication backend, and no cloud storage layer operated by PRIME ISO. All computation — AI prompt assembly, governance scoring, persona generation — runs entirely inside your browser's JavaScript engine.

  • Zero PRIME ISO server-side data reception
  • Session memory cleared automatically on tab close
  • No localStorage, sessionStorage, or cookie writes
  • Outbound requests limited to OpenRouter API (via server-side proxy or direct with custom key) and public CDNs

AI Model Transparency

The Service routes AI requests through OpenRouter to access third-party large language models. The default model is openai/gpt-4o-mini. No proprietary PRIME ISO model is used. Outputs are probabilistic — they can contain errors, hallucinations, or biases inherent to large language models.

Default model

openai/gpt-4o-mini (via OpenRouter)

Prompt routing

Browser → PRIME ISO Vercel proxy → OpenRouter (default); or browser → OpenRouter directly when a custom key is supplied

Important

All AI outputs require human review before use in product decisions. They are not a substitute for verified customer research.

API Key Handling

An optional custom OpenRouter API key can be entered to route calls directly through your own billing account, bypassing the PRIME ISO server-side proxy. The key is handled with strict in-browser isolation.

  • Stored only in a type="password" DOM element — masked on screen
  • Sent only to openrouter.ai over HTTPS when a custom key is active
  • Never logged, transmitted to PRIME ISO, or included in error reports
  • Erased from memory on page close or refresh

Best practice

Set usage limits and credit caps on your OpenRouter account to prevent unexpected charges. See openrouter.ai/docs for key management guidance.

Responsible AI Commitments

PRIME ISO built the governance framework specifically to prevent the misuse of synthetic AI users. Our approach is grounded in the following principles:

  • Human-in-the-loop: The 8-gate framework requires human validation at critical decision points
  • Transparency labeling: Step 8 mandates compliance tags that distinguish AI-generated from human-sourced data
  • Drift detection: The built-in audit tool flags sycophancy and calibration drift in AI personas
  • Scope gating: High-risk decisions are explicitly routed away from synthetic-only validation
  • No deception: The tool is explicitly designed to prevent AI output from being misrepresented as real user research

Compliance & Governance Posture

Our commitments by regulatory domain.

GDPR / UK GDPR

No personal data is collected or processed by PRIME ISO. No data processing agreements are required between the user and PRIME ISO. Prompt data sent to OpenRouter and its underlying model providers is governed by their respective Data Processing Agreements.

CCPA / CPRA (California)

PRIME ISO does not sell, share, or monetize personal information. Because we collect no personal data, no opt-out mechanism is required. California residents have no outstanding rights to assert against PRIME ISO.

SOC 2

As a client-side application with a lightweight server-side proxy, formal SOC 2 certification is not applicable at this time. Enterprise customers requiring SOC 2 coverage should reference OpenRouter's and their selected model provider's compliance documentation.

ISO 27001

PRIME ISO operates with information security management principles aligned to ISO 27001. Formal certification is in assessment. Application code is version-controlled and undergoes security review on each release.

EU AI Act

The Service is a tooling aid for human decision-making, not an autonomous AI decision-maker. Under current classification, it falls outside the high-risk AI system categories defined in the EU AI Act. Transparency disclosures are built into the tool's design.

Responsible AI

PRIME ISO voluntarily aligns with NIST AI RMF and the Partnership on AI's synthetic media guidelines. The 8-gate governance framework is the product's primary mechanism for operationalizing these principles.

Vulnerability Disclosure

If you discover a security vulnerability in the Service — including unintended data exfiltration, third-party script injection, or API key exposure pathways — please report it responsibly to PRIME ISO Services, LLC before public disclosure. We commit to acknowledging receipt within 5 business days and providing a resolution timeline within 14 business days.
